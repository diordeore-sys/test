Welcome to VAULT

Follow these essential setup steps to maximize your tracking performance across all devices:

1

Create Your Master Vault Folder

Before uploading anything, **create one dedicated folder** on your local device storage (e.g., /MyVaultAssets) to pull your raw files from. Keeping files centralized in a single master directory protects your file pathways from breaking and avoids unorganized asset tracking.

2

Linking Artwork & Audio Modules

For audio extensions (`.wav`, `.mp3`) or graphic canvases (`.png`, `.jpg`), you can manually bind direct asset locations, cover arts, and external file targets inside the **Meta Registry** text fields to perfectly link them on-site.

3

Instant State Refresh

The tracking system runs real-time DOM pipelines. If a file grid change does not update immediately due to browser caching, hit the dedicated **Refresh Asset Pipeline** button located directly at the folder tree baseline.
